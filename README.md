# emfls-aquarium

`aquarium.emfls.com`에서 운영할 Aquarium Field Guide의 P0 기반입니다.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run check
npm run build
```

The project uses Astro static output, TypeScript species data, and vanilla CSS. See `SITE_STRATEGY.md`, `DESIGN_SYSTEM.md`, `TASKS.md`, and `PROJECT_HISTORY.md` for decisions and scope.
